# Project documentation

This directory separates the research record from executable code.

- [STATUS.md](STATUS.md): current implementation and verification status.
- [PLAN.md](PLAN.md): ordered development and experiment plan with exit gates.
- [TACC_LONESTAR6.md](TACC_LONESTAR6.md): Lonestar6 deployment and measurement
  guidance.
- [proposal/](proposal/): submitted proposal source and rendered PDF.

The JSONL files produced in `results/` are runtime artifacts and are not source
documentation. A retained experiment should be archived with its manifest,
configuration, request summaries, events, and analysis output.
